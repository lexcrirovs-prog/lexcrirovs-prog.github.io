# Hermes Workspace MCP

Информационные страницы персональной интеграции Google Workspace и ежедневного копирования Яндекс Диска в Google Диск.

Сайт: https://lexcrirovs-prog.github.io/

## Версия

- Версия страниц: **2026.11.10.1**.
- Дата: **10 ноября 2026 года** (Europe/Saratov).
- Исполнитель: **Codex (GPT-6)**.
- Публикация согласована владельцем 10 ноября 2026 года.

## Состав

В `docs/` находятся описание приложения, политика обработки данных, условия персонального использования, локальное оформление и файл подтверждения владения сайтом Google. GitHub Pages публикует только `docs/` из ветки `codex/google-production-20261110`.

Страницы не содержат JavaScript, форм, внешних шрифтов и аналитики. Для изменения содержания нужно обновить HTML/CSS, версию и дату, затем проверить ссылки и опубликованные файлы.

Этот репозиторий содержит только публичные информационные страницы. Он не содержит программу интеграции, ключи доступа, конфигурацию служб или пользовательские документы.

## Проверка выпуска

Структура HTML и локальные ссылки проверены. Основной агент проверил настольное отображение трёх страниц по DOM и снимкам экрана. Мобильное визуальное тестирование не выполнялось. После публикации контрольные суммы HTML/CSS и файла подтверждения сверяются с публичными ответами HTTPS.
