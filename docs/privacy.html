Политика обработки данных

Hermes Workspace MCP · Редакция 10 ноября 2026 года

Эта политика описывает персональную интеграцию владельца с Google Workspace и службу копирования его файлов с Яндекс Диска в Google Диск.

1. Назначение и контакт

Владелец приложения управляет подключёнными аккаунтами и определяет задания для Hermes и копировщика. Публичная регистрация пользователей на этих страницах не предусмотрена.

Контакт по вопросам доступа, обработки и удаления данных: lexcriro.vs@gmail.com.

2. Какие данные обрабатываются

  • Сведения о подключённом аккаунте, необходимые для проверки правильного подключения и доступного места.
  • Названия, идентификаторы, расположение и технические свойства доступных файлов: размер, тип, даты и контрольные суммы.
  • Текст запрошенных документов и содержимое запрошенных диапазонов таблиц.
  • Данные, которые владелец поручает создать или изменить в Google Docs и Google Sheets.
  • Содержимое файлов, передаваемых копировщиком из Яндекс Диска в выбранную папку Google Диска.
  • Ключи доступа и их продления, необходимые для разрешённых обращений к API.

В составе общего приложения используются следующие разрешения. Hermes и копировщик используют свои подключения; ключ копировщика не подменяет ключ Hermes.

Разрешения и назначение
Разрешение GoogleДля чего используется
drive.readonlyПоиск и чтение файлов, доступных подключённому владельцу, в том числе получение текста поддерживаемых форматов.
documentsЧтение, создание и согласованные изменения документов Google Docs.
spreadsheetsЧтение, создание и согласованные изменения таблиц Google Sheets.
drive.fileРабота копировщика с файлами, созданными приложением или предоставленными этому приложению пользователем. Это разрешение не означает доступ ко всему Google Диску.

Экран подтверждения Google показывает разрешения конкретного подключения. Наличие технического разрешения не заменяет поручение владельца выполнить действие.

3. Использование и передача

Интеграция обращается к официальным API Google для выполнения запрошенных операций. Прочитанное содержимое возвращается в Hermes. Если выбранный режим Hermes использует внешнего поставщика модели, необходимые для ответа данные могут передаваться этому поставщику вместе с контекстом запроса.

До передачи содержимого модели владелец должен знать, какой поставщик выбран, и проверить его настройки и условия обработки. Разрешение Google само по себе не подтверждает условия работы поставщика модели.

Копировщик получает файлы из Яндекс Диска и передаёт их через сервер в Google Диск. Эта операция не требует отправлять содержимое копируемых файлов поставщику модели. Сервер может использовать временные файлы и проверенные локальные копии для выполнения переноса.

Ограниченное использование Google-данных

Владелец принимает обязательство использовать и передавать информацию, полученную через Google API, в соответствии с Google API Services User Data Policy, включая требования Limited Use, и политикой данных Google Workspace.

Google-данные используются для явно указанных функций конкретного пользователя. Их продажа, использование для рекламы и передача для обучения или улучшения общих моделей вне персонализированной функции этого пользователя не допускаются. Передача поставщику модели допускается только при условиях, совместимых с этими ограничениями.

4. Хранение

Созданные и изменённые документы, таблицы и копии файлов хранятся в соответствующем Google-аккаунте. Копировщик сохраняет заменяемые версии в архиве и не удаляет из Google файлы только потому, что они исчезли из источника.

Файлы авторизации хранятся отдельно от публикуемого исходного кода. Рабочее состояние, сведения о выполнении и временные данные могут находиться на компьютере владельца и на сервере копирования.

В зависимости от настроек Hermes содержимое запросов и ответов может сохраняться в истории, памяти, журналах и у выбранного поставщика модели. Эти места хранения управляются отдельно. Единый фиксированный срок хранения для них не установлен этой политикой.

5. Управление доступом и удаление

Владелец может остановить копировщик, отключить подключение Hermes и отозвать разрешение в настройках Google-аккаунта. Поскольку Google-проект общий, отзыв его разрешения может затронуть обе функции.

Отзыв доступа не удаляет уже созданные копии, архивные версии, документы, таблицы или историю Hermes. Для удаления этих данных нужно отдельно выбрать соответствующие материалы в Google Диске, локальном хранилище, на сервере или в настройках поставщика модели.

Запросы о сохранённых приложением данных можно направить на lexcriro.vs@gmail.com. Для выполнения запроса потребуется установить, к какому аккаунту и материалам он относится.

6. Эти информационные страницы

На страницах приложения нет собственных форм сбора данных, рекламных трекеров и аналитических скриптов. Переход по ссылке электронной почты открывает почтовую программу пользователя.

Предусмотренный хостинг GitHub Pages может обрабатывать технические сведения о запросах, включая IP-адрес, сведения об устройстве и время посещения. Условия такой обработки описаны в политике конфиденциальности GitHub.

7. Изменение политики

При изменении функций, разрешений или способов обработки данных владелец обновляет эти сведения и дату редакции. Новые способы использования данных требуют соответствующего раскрытия до их применения.
