Персональная интеграция

Документы, таблицы и копии файлов под управлением владельца

Hermes Workspace MCP соединяет помощника Hermes с Google Drive, Google Docs и Google Sheets. В том же Google-проекте работает служба копирования файлов с Яндекс Диска.

Две задачи одного приложения

01 / ПОМОЩНИК

Работа с Google Workspace

По запросу владельца Hermes ищет и читает файлы, получает текст документов и данные таблиц. Он может создавать документы и таблицы, заменять согласованный текст, обновлять диапазоны и добавлять строки.

Инструменты записи требуют явного запроса с целью и содержанием изменения, а также подтверждения операции.

02 / КОПИРОВАНИЕ

Яндекс Диск → Google Диск

Сервер переносит доступные файлы владельца в выбранную папку Google Диска и сохраняет структуру каталогов. Ежедневный запуск настроен на 03:00 по времени Саратова.

Отсутствующие в источнике файлы назначения не удаляются. Заменяемые версии сохраняются в архиве. Завершение копии подтверждается отдельной сверкой.

Как используется содержимое

Для выполнения запроса содержимое документов и таблиц возвращается в Hermes. В зависимости от его настроек оно может направляться выбранному владельцем поставщику модели. Копировщик использует отдельное подключение для переноса файлов между дисками.
